## 🚀 Featured Projects

### 🧭 [Semantic Navigation with ROS 2 & Isaac Sim](https://github.com/juanfranciscosm/isaac-semantic-navigation)

Autonomous semantic navigation system that allows a robot to receive a **natural-language object description**, detect the target using computer vision, estimate its **3D position from RGB-D data**, transform its coordinates using **TF2**, and autonomously navigate toward it using **Nav2**.

**Technologies:** ROS 2 · Python · Nav2 · Isaac Sim · CLIPSeg · RGB-D · TF2

---

### 🤖 [ROSMASTER X3 Simulation & Autonomous Robotics](https://github.com/juanfranciscosm/rosmaster_project)

ROS 2 robotics workspace for simulation, robot control and perception using the **ROSMASTER X3**, including Gazebo simulation, RGB-D sensors and dataset generation for computer vision applications.

**Technologies:** ROS 2 · Gazebo · Python · Computer Vision · RGB-D

---

### 👁️ [ParkVision](https://github.com/juanfranciscosm/ParkVision)

Computer vision system for detecting and monitoring parking-space occupancy using object detection and geometric analysis.

**Technologies:** Python · OpenCV · YOLO · Computer Vision
